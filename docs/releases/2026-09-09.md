# UI 0.3.0 / Web Shell 0.4.0

Turns the reviewed data-workspace interaction rules into reusable components.

UI adds date-range presets and two-click range selection, read-only-first EditableValue, provenance/Undo indicators, fluid CardGrid and stable MetricGrid/KeyValueGrid fields, responsive reading navigation, and one shared loading scope. Card spacing, info-label alignment, compact controls and typography are aligned with the design contract.

Web Shell adds router-independent breadcrumbs and clearer brand/navigation weights. Current pages are non-interactive; ancestors use the host link provider.

Consumers of the composed patterns import `@gitnapp/ui/patterns.css`. Data fetching, router metadata, field ownership and persistence remain in the application. Escape cancels a value edit without closing its containing dialog.

Validation: workspace typecheck, component tests, customization-marker checks, lint, gallery production build, and the research app build/interaction verification. The release includes design.md inside both packages.
